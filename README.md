## 📌 About the Project

This is a client portfolio website built to showcase work, process, and services with a polished, modern feel. The site is structured around a clear narrative — **Home → About → Process → Projects → Contact** — with smooth motion design throughout to make the experience feel premium rather than static.

<br/>

## ✨ Highlights

- 🎬 **Smooth Animations** — Powered by Framer Motion for scroll and interaction-based motion
- 📱 **Fully Responsive** — Built mobile-first with Tailwind CSS 4
- 🧭 **Clear Site Narrative** — Dedicated sections for About, Process, and Project case studies
- ☎️ **Contact Integration** — International phone input support for lead capture
- ⚡ **Fast by Default** — Next.js 15 with Turbopack for dev and build

<br/>

## 🚀 Getting Started

### Prerequisites
- Node.js 18.18+ (recommended: latest LTS)
- npm / yarn / pnpm / bun

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/nrmcodes22/Dees.git
cd Dees

# 2. Install dependencies
npm install

# 3. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

The page auto-updates as you edit files inside `app/`.

<br/>

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the local dev server (with Turbopack) |
| `npm run build` | Create a production build (with Turbopack) |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint checks |
